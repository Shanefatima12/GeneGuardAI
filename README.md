# GeneGuard AI 🧬

### Decode. Detect. Protect.

An interactive genetic variant analysis and disease awareness platform developed for DNA Day.

## Features
- DNA sequence input and comparison
- Mutation identification and classification
- Protein consequence analysis
- HBB sickle-cell educational case
- Genetic Disease Explorer
- Genetics Learning Hub
- Scientific references
- Downloadable educational analysis reports

## Technology Stack
- Python
- Streamlit
- Pandas
- Biopython
